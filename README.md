# Leon Template -  تصميم موقع ويب

#   ملفات المشروع
* index.html: الصفحة الرئيسية للموقع وتحتوي على كافة الأقسام.
* css/style.css: ملف التنسيقات الأساسي للموقع.
* css/all.min.css: ملف مكتبة الأيقونات (Font Awesome).
* images: مجلد يضم  الصور المستخدمة .
* webfonts: مجلد ملفات الخطوط  .

#  أقسام الموقع
1. Header (الهيدر): الشعار وقائمة التنقل المنسدلة.
2. Landing (الواجهة الرئيسية): صورة الخلفية والنص الترحيبي.
3. Features (المميزات): عرض المزايا الأساسية باستخدام CSS Grid.
4. Services (الخدمات): عرض الخدمات مع عمود مخصص للصورة.
5. Portfolio (المشاريع): معرض الأعمال بتصميم بطاقات متناسقة.
6. About (من نحن): نبذة تعريفية مع تنسيقات وإطارات هندسية.
7. Contact (التواصل): البريد الإلكتروني وروابط التواصل الاجتماعي.
8. Footer (الفوتر): حقوق النشر الخاصة بالموقع.


# التقنيات المستخدمة
* HTML5** لبناء هيكلية الصفحة.
* CSS3** للتنسيق والتجاوب مع الشاشات 
* Google Fonts** لاستخدام خط `Work Sans`.
* Font Awesome** لإضافة الأيقونات.


# طريقة التشغيل
افتح ملف `index.html` مباشرة عبر أي متصفح إنترنت (مثل  Microsoft edgeأو Firefox) لعرض الموقع.
